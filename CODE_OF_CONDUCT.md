# Code of conduct

Discuss ideas and behavior directly; treat people with respect. Good-faith
questions, disagreement, and constructive criticism are welcome.

Harassment, threats, personal attacks, discriminatory slurs, sexual harassment
or imagery, impersonation, spam, and publishing another person's private
information are unacceptable. Do not post private clipboard contents,
screenshots, or identifying diagnostic data without permission.

This applies to issues, pull requests, other project spaces, and conduct while
representing the project. The maintainer may edit, hide, or remove content,
lock conversations, or restrict participation. When appropriate, the maintainer
will explain the violated standard without amplifying harmful material.

For content that violates GitHub policy, use GitHub's **Report content** tools;
those reports go to GitHub, not to a private project inbox. A non-sensitive
moderation request may be raised in an issue without reposting the harmful or
private material. Security vulnerabilities use [SECURITY.md](SECURITY.md).
