# Getting help

Use the [question form](https://github.com/JAAvila-Of/laqay/issues/new/choose)
for setup and usage questions. Use the bug form for reproducible failures and
the proposal form for a feature or change in behavior. Search open and closed
issues before submitting. There is no guaranteed response time or paid support.

Include the Laqay release or commit, Windows version/build, whether you are using
a local or remote session, and a short description. Do not share real clipboard
contents, private screenshots, secrets, or unredacted paths and logs.

The README describes current behavior and limitations; the
[integration matrix](docs/integration-tests.md) distinguishes completed checks
from pending work. A feature being planned does not mean it is supported today.
For vulnerabilities, use the private channel in [SECURITY.md](SECURITY.md).
